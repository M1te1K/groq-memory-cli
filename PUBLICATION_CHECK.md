# Проверка подготовки публикации

Дата: 17 октября 2026 года. Назначение: публичный репозиторий M1te1K/groq-memory-cli. Здесь зафиксированы локальные проверки перед первым коммитом; результат загрузки проверяется отдельно по удалённой ветке.

## Сверка требований

Вариант 4 и общие требования исходного задания сверены с кодом, README и автоматическими тестами. Реализованы SQLite-факты имени, города, предпочтений и дополнительно профессии; сохранение в новом процессе; отдельные профили; /forget с удалением фактов, персональных событий и RAM только выбранного профиля; /reset с сохранением фактов. Таблица events содержит время UTC, user_id, запрос, ответ и операции памяти. Ошибки Groq дают «Сервис временно недоступен» и не завершают CLI; ошибки проверки памяти имеют отдельное сообщение.

Матрица требований и тестов находится в [ARCHITECTURE.md](ARCHITECTURE.md). README включает чистую установку, переменные, запуск, все команды, просмотр логов в режиме read-only и типичные ошибки. [SUBMISSION.md](SUBMISSION.md) содержит текст для сдачи без выдуманного времени.
